# კონტენტის მართვის მოკლე ინსტრუქცია

ეს ინსტრუქცია ეხება ადმინისტრაციულ პანელს (CMS). ყველა ცვლილება საჯარო საიტზე დაახლოებით ერთ წუთში ჩანს. კოდის შეცვლა საჭირო არ არის.

**პანელის მისამართი:** `https://stemdialogue.com/projects/school2university/admin` (ლოკალურად: `http://localhost:4200/projects/school2university/admin`; მოკლე მისამართი `/admin` იქ გადაგიყვანთ). შედით ელფოსტითა და პაროლით, რომელსაც ადმინისტრატორი მოგცემთ. პაროლის შეცვლა — ზედა მარჯვენა კუთხეში თქვენს სახელზე დაჭერით.

## როლები

- **ადმინისტრატორი** — ყველაფერი, მათ შორის მომხმარებლები, დაფინანსებისა და პარტნიორების ტექსტები და ორგანიზაციები.
- **რედაქტორი** — სიახლეები, ღონისძიებები, პროფილები, რესურსები, გვერდები და მედია.

## სურათების ატვირთვა

1. **მედია → ატვირთვა.** დაშვებულია JPG, PNG, WebP, GIF და SVG (10 MB-მდე), ასევე PDF, PPTX, DOCX და XLSX (50 MB-მდე).
2. აუცილებლად შეავსეთ **Alt ტექსტი** ქართულად, ანუ რა ჩანს სურათზე. ეს საჭიროა ხელმისაწვდომობისთვის.
3. ვიდეოს ატვირთვა არ ხდება. ატვირთეთ YouTube-ზე ან Vimeo-ზე და საიტზე ჩასვით ბმული.
4. ლოგოები ატვირთეთ ორიგინალი ფაილით: არ დაჭიმოთ და არ გადააფეროვნოთ.

## სიახლის დამატება

1. **სიახლეები → ახალი.** შეავსეთ სათაური, მოკლე ანოტაცია და ტექსტი. ინგლისური ველები არასავალდებულოა.
2. აირჩიეთ კატეგორია: განცხადება, შეხვედრის ანონსი, შეხვედრის შეჯამება, კონკურსი/შესაძლებლობა, მიღწევა/შედეგი ან ზოგადი სიახლე.
3. დაამატეთ ყდის სურათი, საჭიროების შემთხვევაში გალერეა, თეგები და დაკავშირებული შეხვედრა.
4. **შენახვა** ქმნის დრაფტს, რომელიც საიტზე არ ჩანს.
5. **გამოქვეყნება** აქვეყნებს მაშინვე. მომავალი თარიღის მითითებით შეგიძლიათ დაგეგმოთ გამოქვეყნება.
6. „მთავარ გვერდზე გამოჩენა“ სიახლეს მთავარ გვერდზე გამოიტანს.

გამოქვეყნებული სიახლე არ იშლება: საჭიროების შემთხვევაში დააარქივეთ. თუ URL-ს (slug-ს) შეცვლით, ძველი ბმულიც იმუშავებს.

## STEM შაბათობის (ღონისძიების) დამატება და დასრულება

1. **ღონისძიებები → ახალი.** შეავსეთ თემა, თარიღი და საათი (თბილისის დროით), ფორმატი (ონლაინ/ფიზიკური/ჰიბრიდული), ადგილი ან ტრანსლაციის ბმული, რეგისტრაციის ბმული და მიმართულება.
2. **მონაწილეები:** აირჩიეთ მკვლევრები ან მენტორები არსებული პროფილებიდან. საჭიროების შემთხვევაში ჯერ შექმენით პროფილი.
3. **გამოქვეყნება:** ანონსი გამოჩნდება „მომავალ შეხვედრებში“.
4. **შეხვედრის შემდეგ** დააჭირეთ **დასრულებას**, ჩაწერეთ შეჯამება და ჩანაწერის ბმული. შემდეგ რედაქტირებით დაამატეთ ფოტოები, ხოლო „რესურსებში“ ატვირთეთ პრეზენტაცია და მიაბით ამ ღონისძიებას. გვერდი იმავე მისამართზე გადავა არქივში.
5. **გაუქმება ან გადატანა:** გამოიყენეთ შესაბამისი ღილაკი და დაწერეთ შეტყობინება. ძველი ბმული შენარჩუნდება და სტატუსი საიტზე მკაფიოდ გამოჩნდება.

## პროფილის (მკვლევარი, მენტორი, გუნდის წევრი) დამატება

1. **ადამიანები → ახალი.** შეავსეთ სახელი და გვარი, ფოტო, მოკლე და სრული ბიოგრაფია, წოდება, თანამდებობა, ორგანიზაცია და წვლილი.
2. **როლები:** ერთ ადამიანს შეიძლება ჰქონდეს რამდენიმე როლი. მაგალითად, ერთი პროფილი შეიძლება იყოს ერთდროულად მკვლევარიც და მენტორიც. გუნდის როლებია:
   - შემსრულებელი გუნდი (ოფიციალური საგრანტო პერსონალი);
   - მოწვეული კონსულტანტი;
   - ტექნოლოგიური გუნდი;
   - საორგანიზაციო და ტექნიკური პერსონალი.
3. როლს მიუთითეთ დაწყების თარიღი. როცა ადამიანის ჩართულობა დასრულდება, **მიუთითეთ დასრულების თარიღი** და ნუ წაშლით პროფილს. მისი წვლილი არქივში დარჩება.
4. სტატუსი **„გამოქვეყნებული“** პროფილს საიტზე გამოაჩენს. დაუდასტურებელი პროფილი დატოვეთ დრაფტად.
5. ელფოსტა შიდა ინფორმაციაა და საიტზე არ ჩანს.

## STEM ელჩების აქტივობები

იდენტიფიცირებადი ფოტოები (არასრულწლოვნები) ქვეყნდება მხოლოდ მაშინ, როცა მონიშნულია **„ნებართვები დადასტურებულია“** და მითითებულია დოკუმენტის რეფერენსი. მოსწავლეების პირადი პროფილები არ იქმნება.

## დაფინანსება და პარტნიორები (მხოლოდ ადმინისტრატორი)

**პროექტის პარამეტრებში** იცვლება ორი ტექსტი: Header-ის მოკლე ზოლის ფორმულირება და Footer-ის სრული ოფიციალური ფორმულირება. იქვე იმართება პარტნიორების სია. ფონდი მონიშნულია როლით **„დამფინანსებელი“**, ბტუ და აწსუ კი — როლით **„პარტნიორი უნივერსიტეტი“**. ლოგოები და ვებგვერდების ბმულები იცვლება **ორგანიზაციებში**.

## თუ შენახვისას გამოჩნდა „ჩანაწერი შეიცვალა სხვის მიერ“

ამავე ჩანაწერს სხვა რედაქტორიც ცვლის. გადატვირთეთ გვერდი, ნახეთ მისი ცვლილებები და თქვენი ცვლილება თავიდან შეიტანეთ.
